# Noob31's Notes

Created as an alternative to Obsidian on web.
Work in Progress and compatible with obsidian formatting.
Includes canvas and graph view.
Works in-browser and uses github to sync.
Also works without login in browser.

(I am aware of many of the bugs and am attmepting to fix it. This project was created partly with AI assistance (Claude Opus/Gemini.))

Demo: https://notes.noob31.com/

Build and deploy:

node:
```
npm i
npm run build
```

Serve from `/dist`.
